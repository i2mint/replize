# replize

Tools for make REPL interfaces.

`replize` is a function that converts a command line program into a REPL.

```pycon
>>> from replize import replize
>>> replize("ls")
```

| [`replize`](replize.replize.html.md#replize.replize)(command, \*[, prompt_template, ...])   | Converts a command line into a REPL.   |
